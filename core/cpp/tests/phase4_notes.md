# Phase 4 — World Model + Self Model

This layer makes world-state conflict and internal capability state explicit and testable.

- Conflicting facts are retained as disputed evidence rather than discarded.
- Conflicting relations are retained and surfaced as disputed.
- Observation events can populate explicit subject/predicate/object relations.
- Self-state reflects active goals, aggregate capability health, workload pressure, and per-capability resource pressure.
- Capability state is reconstructed from the persistent cognitive event journal.
