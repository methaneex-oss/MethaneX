## 3. Cross-path conclusions

1. **Affect has downstream consumers.** The donor's affective state is consumed by intent/planning and by action-outcome evidence weighting. It is not merely an isolated state variable. Its scope remains bounded, and its appraisal equations are engineered priors.
2. **Action feedback is Brain-owned in this donor path.** The Brain forecasts, executes through an authorization boundary, records action context/outcome evidence and resolves consequence predictions. This is a valuable donor path, not proof that the main branch already owns the same complete loop.
3. **Developmental learning can alter later choices.** Context-derived strategy evidence is applied to candidate action utility/expected value. Transfer is based on a fixed context representation and similarity machinery; this is not unrestricted generalization.
4. **Prediction feedback is present but improvement is an empirical question.** Prediction resolution and adaptation state updates must be evaluated with held-out metrics, not inferred from the presence of an API.
5. **Persistence is event-based, not synonymous with trustworthy memory.** Replay can reconstruct recorded state, but integrity, rollback resistance, semantic retrieval and version migration require separate verification.
6. **Evolution is gated, not unrestricted.** The controller checks evaluation evidence and isolation; the stateless helper intentionally fails closed. Residual compensation failure tests remain a separate gate.
